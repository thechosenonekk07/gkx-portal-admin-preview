# 页面停留、按钮点击率与建议联动核查

以下初版记录保留追溯；当前布局与交互以文末“纵向柱图与联动升级”为准。

日期：2026-11-05。模式：full。范围：两图一卡、统一查询与原统计的数据隔离。沿用项目React运行时、普通CSS及GKX视觉规范，无新增依赖。

## 已确认口径

用户先要求分析，随后接受有效曝光访问去重点击率，并确认前台可见平均停留；两项定义明确后进入原型实现。

- 平均停留＝总有效可见毫秒／有效访问次数。后台时间不包含在visibleMs内；有效0秒访问保留，无样本显示—。
- CTR＝点击访问数／有效曝光访问数。同一次访问同一按钮只计一次有效曝光，曝光后至少点击一次只计一次点击访问；重复曝光、点击与访问重试不重复累计。
- 跨午夜不换访问ID，两类计量按北京时间访问开始日期归属，仅纳入已结束有效访问。日/月/年均先合计分子分母再除。
- 新计量独立于原业务counts，不增加旧事件总量、排行与漏斗次数。首版配置8页面、8正向业务按钮，不将所有埋点当作按钮。
- 最低三项来自完整有效候选。零点击保留，零曝光/坏数据不冒充0%；不参与优化的历史按钮可保留图中数据。并列按曝光降序、自然ID序；不足3项不补造。
- 三条用户原文模板按按钮稳定随机匹配，可重复；跨查询不跳变。只提供尝试方向，不依据低率推定确定原因。

## 考虑并放弃

1. 事件占比替代CTR：分母错误，且漏掉零点击按钮。
2. 累计后台挂页：不符合用户确认的有效可见时长。
3. 每次渲染随机建议：悬浮、缩放和查询会无依据地改变文案。
4. 所有低率标红并判定原因：最低项只是候选，需要查看样本再验证。
5. 三块挤在同一排：两图并排、建议另起一行；手机保留上下顺序。

## 纵向柱图与联动升级（2026-11-05）

用户明确授权按分析后的理解实施并预览判断。参考所提供Figma中图表的白底、细网格、轻边框及12/14px信息层级，转换为适合当前分类比较的动态纵向柱图，沿用GKX蓝色与既有统计口径；未导入参考产品页面、静态曲线或私有设计资产，也未声称逐像素复刻某个柱状图节点。

### 当前结构与交互

- 停留图独立整行：真实纵轴、零起点与漂亮刻度；默认上限250秒，刻度0/50/100/150/200/250。完整数值置于柱顶。
- 点击率图与建议共用一个外卡和加载边界；桌面左图右建议，窄屏在同一容器内上下排列。默认点击率范围0..30%，按有效候选最低三项加深柱色，当前选择另用背景带和下划线表达，普通项被选中不会误装成低率项。
- 保留全部8个按钮及3个最低项入口。默认固定首项；悬浮/方向键只预览，点击/Enter固定。移出预览回到固定项，建议点击不把页面纵向跳去图表，仅必要时平移图内视口。非最低项有真实曝光/点击/率摘要，不附加模板。
- 0值保留完整列命中区及基线标记，无数据使用—和虚线标记；均不补假柱高。移动端横向滚动整张图，名称可两行显示，浮层包含完整名称、路径和公式。
- keyboardMode隔离键盘滚动导致的静止指针mouseenter，实际鼠标移动重新接管预览；首末列同节点Home/End在Esc后也会显式同步预览。浮层同时检查自身与锚点的可见裁切边界。
- 共7个ResultModule同步busy/inert（原5块＋停留＋点击率联动），更新数据时保留仍然存在的固定选择。
