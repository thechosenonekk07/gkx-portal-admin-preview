# 埋点统计原文与细化稿的展示取舍

本记录依据用户后续补充的需规原文第132条，回答“环比是否有必要”“转化率是否要求漏斗”，并记录用户授权评估后的原型裁剪。第131条新增事件和第133条信息管理不在本轮修改范围。

## 需求依据

原文明确要求按年、月、日时间区间统计五类内容：事件总量、活跃用户数、事件排行、事件增长趋势、事件转化率。原文没有明确要求环比、上期值或特定图表形态。

V1.5第1.3节是更细的方案，明确写入了两个指标的上期值／环比和业务流程漏斗。它与原文并不直接冲突：原文说明目标，细化稿增加了展示与计算方案。此前“环比和漏斗必须保留”的判断针对V1.5细化稿成立，但不能据此说原始需规也硬性指定了这两种展示。

## 当前取舍

| 项目 | 必要性分析 | 当前处理 |
| --- | --- | --- |
| 两张指标卡的环比与上期值 | 能补充本期相对上一周期的变化，但属于额外比较能力。当前主要任务是查看本期规模、区间增长、功能点排行和流程转化；比较周期还需额外定义跨月、进行中区间、历史不足等口径 | 按用户“没必要可以删掉”的授权，移除卡片百分比、上期值和独立上期日期；同步移除未使用的上期计算与历史记录生成 |
| 事件增长趋势 | 原文明确要求，呈现本期按日／月／年的变化，不能因删除环比而删除趋势 | 保留，数据点、两个系列、悬浮和键盘查看不变 |
| 事件转化率 | 原文明确要求，是五项核心统计之一 | 保留步骤触发次数比及整体转化率 |
| 纵向漏斗图 | 原文未指定必须使用，但其“完整业务流程”分析目标需要呈现步骤先后和次数变化，漏斗是适合的展示方案 | 保留已实现的纵向居中漏斗，共用次数尺度、相邻步骤间显示转化率；不是将漏斗本身当作原文强制条款 |
| 默认近30日、登录UV、预置4／3／3流程、查询状态 | 原文没有给出这些细节，V1.5与此前已确认实现提供了具体方案；本次问题没有要求变更这些功能 | 保留现有行为，避免把展示取舍扩大成未授权的流程改造 |

删除环比不意味着环比没有分析价值，而是本轮不将它作为基础原型的必需项。当前五项核心统计仍然完整；如后续有明确的跨周期运营比较需求，需要再统一比较口径。

## 口径边界

原文还提到页面停留时间、按钮点击率等分析场景。停留时间需要页面进入／离开或活动状态等时序数据；按钮点击率需要明确定义点击数和对应曝光或访问分母。当前流程转化率按V1.5的“后一步触发次数／前一步触发次数”计算，不能直接替代前述两种指标。

本轮聚焦用户提出的环比和漏斗，不新增缺乏采集与分母定义的指标，不宣称生产埋点采集与这些分析场景已完成验收。

## 验证

- 删除前后5组日／月／年／部分覆盖／未来窗口的当前结果逐项一致：总量、登录UV、身份拆分、趋势、排行、三流程与覆盖元数据均未改变。
- 页面实际检查无“环比”“上期”“上一周期”文本，无残留对比节点；默认当前总量114,711、登录UV1,194，搜索漏斗20,525→13,245→7,658→3,995及整体19.5%不变。
- 按月查询仍为1,151,904／4,093；切换工作台保持三步，重置恢复近30日及搜索流程。模型16项、查询生命周期10项检查通过。
- 模型不再返回任何上期值、上期区间或涨跌幅，也不再生成查询区间以外的上期样例记录。
